#A Small Encrypted TCP Chat Room

A multi-client, real-time TCP chat room application built in Python, featuring a Tkinter graphical user interface, multithreaded socket networking, and end-to-end Fernet symmetric encryption.

##  Repository Structure

```text
.
├── server.py   # Multithreaded TCP Socket Server (Connection Manager & Message Broadcaster)
└── client.py   # Tkinter GUI Client (Encryption/Decryption & Socket Listener)
```

### `server.py` — TCP Chat Server
Built using Python's built-in `socket` and `threading` libraries.
- **Concurrent Connections:** Spawns a dedicated thread per connected client to handle simultaneous incoming and outgoing traffic without blocking.
- **Message Broadcasting:** Relays encrypted payloads across all active clients in real time while managing join/leave notifications and disconnects.

### `client.py` — Encrypted GUI Client
Built with **Tkinter**, **socket**, **threading**, and **cryptography (Fernet)**.
- **Fernet Symmetric Encryption:** Encrypts outgoing messages before transmission and decrypts incoming payloads locally so plaintext never travels over the wire.
- **Tkinter Interface:** Clean desktop chat window with a live message feed, active user/connection controls, and non-blocking background socket listening.
